# 金鳞抽卡导出小助手（Android 端）

一个**本地运行**的抽卡记录统计工具：读取**你自己账号**的游戏抽卡记录，在手机本地完成去重、保底追踪与统计展示。

**不修改任何网络数据、不上传任何数据、不需要 root。**

> **版本状态：技术预览版（Technology Preview）· `v0.1.0-preview.1`**
> 功能可用、单元测试全绿，但**仍在演进中，可能存在尚未发现的问题**，请勿当作稳定版使用。
> 另请注意：**元数据需自行配置**（见 §6）。遇到问题请开 Issue。

---

## 1. 这是什么

- **目标游戏**：《夜幕之下》（Android 端）
- **纯本地**：全部解析与统计都在手机本地完成，数据存在应用私有目录里
- **四个页面**：
  - **抓包页**：开始 / 停止读取，实时日志，把当前这次抓到的记录列出
  - **记录页**：本次读到的抽卡记录（去重后）
  - **统计页**：保底进度、卡池分布、稀有度分布等，并可管理多账号
  - **设置页**：账号与数据维护、元数据、关于

## 2. 这是什么 —— 以及**不是什么**

为了避免误解，把边界一次说清：

| 本工具**会**做的事           | 本工具**不会**做的事                         |
| --------------------- | ------------------------------------ |
| 在手机本地读取你**自己**的游戏抽卡记录 | ❌ 修改数据包内容（载荷逐字节原样转发）                 |
| 在本地做去重、保底追踪、统计分析      | ❌ 重放请求、伪造数据包来源                       |
| 把结果保存在应用私有目录          | ❌ 模拟点击、自动抽卡、代打代练                     |
| ——                    | ❌ 读取游戏本地文件、注入进程、使用 root / 无障碍 / 调试权限 |
| ——                    | ❌ 上传任何数据到任何服务器（见 §4）                 |

**权限清单**（可在 `android/app/src/main/AndroidManifest.xml` 核对）：

- `INTERNET` —— 转发层需要建立真实网络连接
- `FOREGROUND_SERVICE` / `FOREGROUND_SERVICE_DATA_SYNC` —— 前台服务（Android 要求）
- `POST_NOTIFICATIONS` —— 前台服务通知

**没有**任何存储、通讯录、位置、相机、无障碍、查询已安装应用等权限。

## 3. 工作原理（透明说明）

1. 通过 Android 系统提供的 `VpnService` 建立**本地**隧道，并**只接管目标游戏**这一个应用（`addAllowedApplication`）——其它 App 的流量走系统原路径，不受影响；
2. 目标游戏的连接由本应用在**内存中**做 TCP 中转：给游戏侧回包的是内存里的虚拟连接，同时另建一条**真实 socket 直连游戏服务器**（`protect()` 使其绕开自身隧道）；
3. 载荷**逐字节原样转发**；本应用只在旁路复制一份用于解析与统计。

相关实现全部在本仓库内，可自行审阅：

- `core/` —— 帧切分、记录解析、去重、统计
- `vpn/` —— 隧道与转发层（上文第 1–3 点）
- `ui/` —— 界面

## 4. 安全声明

- **只读**：不修改、不重放、不伪造；
- **不联网上传**：应用内没有任何数据上报、统计埋点、自动更新回传。唯一的外发请求是**你手动触发**的"拉取元数据"（见 §6），且只发送鉴权头、不发送你的任何记录；
- **可自证：断网仍可用**。开启飞行模式后，已抓取的记录与统计依然能正常查看——这说明它没有"偷偷上传"的通道；
- 应用不收集任何个人信息，不含账号体系。

## 6. 元数据配置（**重要，请先读**）

界面里把卡池 / 角色 ID 显示成名字，依赖一份**元数据**（角色名、稀有度、卡池与保底组配置）。

**本仓库是源码公开版，不含服务端凭据**：`network/MetadataClient.kt` 里的接口地址 / KEY / SECRET 均为**占位值**：

```kotlin
const val DEFAULT_ROLE_URL = "https://example.com/v1/role"   // 占位
const val KEY = "example-key"                                // 占位
const val SECRET = "example-secret-not-real"                 // 占位
```

因此**开箱状态下拉不到元数据**，统计页会以 ID 显示。想让名字显示出来，任选一种：

1. **自行配置数据源**：替换上面三个常量（或改为构建期注入，推荐）；你自己的服务端需按同套鉴权约定实现（HMAC-SHA256 签名，见 `persistence/HmacSign.kt`）；
2. **离线放置**：把符合 `core/meta/MetaParser.kt` 结构的 JSON 放到应用私有目录的 `cache/role_cache.json`。

> 说明：客户端里的凭据**无法保密**（APK 可被反编译），所以这类凭据不宜由作者代替使用者保管；请使用你自己的数据源。

## 7. 环境要求与构建

| 项           | 值                                   |
| ----------- | ----------------------------------- |
| JDK         | 17                                  |
| Gradle      | 8.9（仓库内含 wrapper）                   |
| Android SDK | compileSdk / targetSdk 35，minSdk 28 |
| 语言 / UI     | Kotlin + Jetpack Compose            |

```bash
cd android
./gradlew :app:testDebugUnitTest     # 跑单元测试（纯 JVM，无需设备）
./gradlew :app:assembleDebug         # 产出 app/build/outputs/apk/debug/app-debug.apk
```

> 仓库内的 APK 使用 **debug 签名**，仅供调试。若要分发，请使用你自己的 release keystore 签名，并开启代码混淆。
